# 咖啡廳打工日記｜3D 人物互動版規格書

## 一、作品介紹

《咖啡廳打工日記》是一款以咖啡廳服務為主題的單人 3D 網頁遊戲。玩家扮演咖啡師，在有限的營業時間內製作餐點、從出餐檯取餐、送到顧客桌邊，並在顧客用餐後完成收銀找零。

遊戲以可移動的 3D 人物和咖啡廳場景為主要介面。玩家使用鍵盤控制角色，接近工作站、出餐檯、垃圾桶或顧客桌後進行互動。遊戲以日數、倒數時間、營收、分數、商譽心數及連擊顯示營業狀況。

作品以 HTML、CSS、JavaScript 與 Three.js 製作，主要程式碼整合在單一 `index.html`，Three.js 由 CDN 載入。

## 二、設計目標

1. 建立包含櫃檯、飲品與甜點工作站、出餐檯、垃圾桶及顧客座位的 3D 咖啡廳。
2. 讓玩家以鍵盤移動角色，並依照顧客需求完成製作、取餐、送餐與找零。
3. 以各工作站的製作時間和排隊上限呈現簡易工作流程。
4. 以顧客耐心、營業倒數及商譽心數帶來時間管理挑戰。
5. 以營收、分數、連擊及每日結算呈現營業成果。
6. 讓主要遊戲操作可使用鍵盤完成，並保留滑鼠按鈕操作方式。

## 三、場景與人物

### 3.1 咖啡廳場景

| 區域 | 功能 |
|---|---|
| 咖啡機 | 排隊製作美式咖啡、拿鐵及卡布奇諾 |
| 蛋糕櫃 | 排隊製作起司蛋糕、巧克力蛋糕及提拉米蘇 |
| 麵包架 | 排隊製作可頌、貝果及肉桂吐司 |
| 出餐檯 | 從已完成的餐點中選取一份，拿在手上 |
| 垃圾桶 | 丟棄手上不需要的餐點 |
| 顧客桌 | 送餐；顧客用餐完成後可開啟收銀機 |

玩家必須走近目標，畫面才會顯示對應的互動提示。當多個互動目標距離相近時，系統選取距離玩家最近且符合目前狀態的目標。

### 3.2 人物與攝影機

玩家角色與顧客以 Three.js 幾何模型組合呈現。角色移動時會播放行走動作，靜止時會播放待機動作。顧客會由入口走到座位，完成服務或耐心耗盡時再往出口離開。

攝影機使用固定視角呈現整個咖啡廳，不支援滑鼠拖曳轉動或縮放。

## 四、玩家操作方式

### 4.1 遊戲場景操作

| 操作 | 功能 |
|---|---|
| W／↑ | 向場景前方移動 |
| A／← | 向左移動 |
| S／↓ | 向場景後方移動 |
| D／→ | 向右移動 |
| E | 與目前距離最近的有效目標互動 |
| 滑鼠點擊 | 聚焦 3D 場景，或操作畫面上的按鈕 |

開始遊戲或重新開始後，鍵盤焦點會回到場景。若要移動角色，請先讓場景取得焦點。遊戲沒有加速鍵、暫停按鈕或攝影機視角控制。

### 4.2 工作站選單

- 走近咖啡機、蛋糕櫃或麵包架後按 E 開啟選單。
- ↑／↓ 移動品項選擇；Enter 或 E 將選取品項加入製作佇列。
- 也可用 Tab 移動至選單按鈕，再以 Enter／空白鍵操作。
- 按其他非導覽或指定操作鍵可關閉工作視窗；選單關閉按鈕亦可用滑鼠或鍵盤操作。

### 4.3 出餐檯選單

出餐檯只有一份餐點時，按 E 可直接拿取。若有多份餐點，按 E 開啟清單，使用 ↑／↓ 選擇餐點，再按 Enter 取餐；也可使用 Tab、Enter／空白鍵或滑鼠操作按鈕。

### 4.4 收銀找零視窗

走近已用餐完成、正在等待付款的顧客桌，按 E 開啟收銀機。操作方式：

- ↑／↓／←／→：在找零面額按鈕之間移動。
- Enter：加入目前選取的面額。
- Shift+Enter：確認並送出找零。一般 Enter 只會加入目前選取的面額，不會送出找零。
- Backspace／Delete：清空目前湊出的金額。
- Tab：在視窗的可操作按鈕間移動。

也可使用滑鼠點擊面額、清空、確認或暫時關閉按鈕。找零金額必須與應找金額完全一致，才能完成收款；錯誤金額不會完成結帳。

### 4.5 其他操作

- 頂部喇叭按鈕可切換音效靜音狀態。
- 手上拿著餐點時，走近垃圾桶並按 E 可丟棄餐點；已丟棄的餐點不會回到出餐檯。
- 開始、下一天及重新開始等畫面按鈕可使用 Tab 聚焦，並以 Enter／空白鍵操作。

### 5.2 製作佇列

三個工作站各自有獨立佇列。每站最多容納 3 份待製作餐點，包含正在製作的一份和排隊中的餐點。每項餐點依照上表的製作時間完成，完成後自動放到出餐檯。

玩家可以在未對應某位顧客進行付款前先行製作；工作站不會依顧客訂單自動限制品項。玩家需自行根據顧客桌牌上的餐點圖示與金額安排製作。

## 六、顧客與服務流程

### 6.1 顧客進店與訂單

遊戲開始後約 1.5 秒進行第一位顧客的生成嘗試。之後會依日數設定的隨機間隔進行生成嘗試；若仍有空位，就在第一個空位安排顧客。每天座位數逐步增加，最多 4 位：

| 日數 | 座位數 |
|---|---:|
| 第 1–2 天 | 2 |
| 第 3–4 天 | 3 |
| 第 5 天起 | 4 |

顧客入座後先處於思考狀態，約 0.9 秒後產生訂單。訂單隨機包含 1 至 3 種不同品項，各品項不重複；品項數量皆為一份。不同訂單種類數的機率分別為一種 50%、兩種 35%、三種 15%。顧客桌牌顯示餐點圖示及訂單總額。

### 6.2 製作與送餐

玩家按顧客桌牌上的圖示，到對應工作站製作需要的餐點。完成的餐點會出現在出餐檯；每次只能拿一份在手上。

拿著餐點走近顧客桌並按 E，即可嘗試送餐。餐點必須符合該顧客尚未送達的訂單品項；若沒拿餐點或送錯品項，送餐不成功並有錯誤回饋。每成功送達一項，顧客耐心恢復至目前日數設定的上限。訂單所有品項都送達後，顧客用餐約 1.5 秒，接著進入等待付款狀態。

若手上拿錯或不需要的餐點，可至垃圾桶旁按 E 丟棄，再回出餐檯選取其他餐點。

### 6.3 收銀與找零

顧客用餐完成後，桌牌會顯示收款按鈕及應付總額。玩家可點擊該按鈕，或走近桌子按 E 開啟收銀機。收銀機顯示訂單金額、顧客付款金額、應找金額及目前湊出的金額。

顧客付款方式如下：15% 機率剛好支付訂單總額；否則支付 100、500 或 1000 元中最小且足以支付訂單的金額。可用面額為 1000、500、100、50、10、5、1 元。玩家湊出的面額總和必須等於應找金額；若金額不正確，收款不會完成，且顧客耐心額外減少 1.5 秒。

成功找零後，訂單總額加入營收，顧客離場，完成服務數及分數更新，連擊增加。分數依訂單金額、剩餘耐心比例及目前連擊計算。

## 七、顧客耐心、商譽與分數

### 7.1 顧客耐心

顧客耐心以毫秒計算，起始及送達餐點後回復至當日耐心上限。耐心上限隨日數下降：

**每日耐心上限 = max(30 秒 − (日數 − 1) × 2 秒，14 秒)**

顧客在等待點餐及等待付款時會消耗耐心；思考、用餐期間不消耗。耐心歸零時顧客生氣離場，商譽心數減少 1，連擊歸零。

### 7.2 商譽心數

遊戲開始時有 3 顆商譽心。商譽降至 0 時立即結束營業並顯示遊戲結束畫面。若整天沒有顧客生氣離場，當日結算時恢復 1 顆商譽心，最多 3 顆。

### 7.3 營收與分數

成功收款時，營收增加訂單總額。遊戲不計算小費或 0–100 顧客評價；以分數、連擊及商譽心數呈現服務結果。

每次成功服務的分數為：

**round(訂單總額 ÷ 10 + 剩餘耐心比例 × 20 + 目前連擊 × 2)**

分數加入總分及當日分數，連擊加 1，並更新最高連擊。

## 八、營業時間與結算

每個營業日為 70 秒倒數（顯示為 1:10 起始）。第一天顧客生成間隔為 4–7 秒；往後每增加一天，間隔範圍減少 0.3 秒，最短間隔不低於 2 秒，最長不低於 4 秒。每次生成計時到期會嘗試找空位；沒有空位時不會生成顧客。

倒數歸零後不再嘗試生成顧客；等場上顧客全部完成服務或離場後，才顯示當日結算。結算包含當日服務人數、生氣離場人數、營收與分數。玩家可選擇進入下一天，座位數、耐心上限及顧客生成速度會依日數調整。

商譽心歸零會立即進入遊戲結束畫面，顯示經營天數、服務總人數、總營收、總分數及最高連擊。玩家可重新開始，重置遊戲狀態與統計。

遊戲沒有暫停功能。開始營業前的介紹視窗、每日結算、遊戲結束、工作站、出餐檯及收銀機均使用視窗呈現。

## 九、介面與即時回饋

### 9.1 頂部狀態列

顯示目前日數、倒數時間、累計營收、分數、商譽心數、連擊及靜音切換按鈕。

### 9.2 場景提示與顧客桌牌

玩家接近有效互動目標時，場景中會顯示 E 互動提示。顧客桌牌依狀態呈現思考提示、訂單餐點圖示與總額、用餐狀態或收款按鈕；等待服務或付款時並顯示耐心進度條。

### 9.3 工作視窗與訊息

工作站視窗顯示目前製作狀態、進度與佇列數；出餐檯列出已完成餐點；收銀機列出應付、實付、應找及已湊金額。完成製作、送餐、收款、錯誤操作及丟棄餐點時會以音效或短暫訊息回饋。

### 9.4 色彩與動態

介面支援淺色／深色系統偏好，也可套用對應的主題色。使用者啟用減少動態效果偏好時，部分動畫會停用或降低。

## 十、特殊情況處理

| 情況 | 系統處理 |
|---|---|
| 玩家未靠近可互動目標 | 不執行互動；移動至目標附近後會出現操作提示 |
| 工作站佇列已滿 | 工作站品項按鈕停用，無法繼續排隊 |
| 出餐檯有多份餐點 | 顯示餐點選單，可用上下鍵或按鈕選取 |
| 手上已有餐點 | 不可再從出餐檯取餐；可先送餐或到垃圾桶丟棄 |
| 送錯餐點或沒有拿餐點 | 不完成送餐，顧客顯示錯誤回饋 |
| 找零金額不符 | 不完成收款，顧客耐心減少 1.5 秒 |
| 顧客耐心歸零 | 顧客生氣離場，商譽減少、連擊歸零 |
| 遊戲倒數歸零但仍有顧客 | 停止新增顧客，待場上顧客離場後結算 |
| 商譽歸零 | 立即結束營業並顯示總結畫面 |
